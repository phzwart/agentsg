# Wall-incidence census

Measured cells from a `CellDatabase`, scored with the Selling-closure helpers in `manuscript/benchmark/evaluate.py` and `manuscript/appendix_z/test_z44_widened_complete.py`. No library code is changed.

Database `data/cod_cells.duckdb`. Seed `0`. Sample `None`. Loaded **528,439** cells. Closure pass: **full** on 528,439 obtuse cells. Metric batch on **cuda**, closures and sort paths on **20** processes (2941.21 closure cells/s). A full closure pass would take 0.05 h.

The reduced superbase is built from the stored Selling cell. `tau` is three times the largest conorm standard deviation, and never smaller than `1e-9 max|G|`. A parameter fixed by the reported crystal system (a 90° or 120° angle, or a length the system equates to another) has σ = 0. `tau_kind = esd` when every free parameter has an esd and at least one of those esds is positive; otherwise the nominal errors are `0.001 * length` and `0.03` degrees. A sort path imposes cosine-scaled zeros and ties in order. Equal cosine crossings are one step. A step is kept only when the next closed pattern contains the previous one and adds a constraint, so a path from six free conorms to one has at most five steps. Each constraint set is replaced by the finest closed Table 4 pattern that contains it. A transition is inside the measurement when its cosine is within `3 σ(p)` of that slot, scaled by the edge lengths. The per-slot closure is `consistent_construct`: esd rows use `sigma = 3 max σ(p_ij)/(|u_i||u_j|)`, nominal rows use `sin(0.03°)`. `ok` is Conjecture A6''. The 3° table uses `sigma = sin(3°)/4` on every cell. `d_sig` uses the largest slot sigma in a class and ignores covariances.

## Tolerance calibration

Distances are read while the path sits in the source sort of each Table C2 edge. `d_cos` is the cosine of a zero class or the cosine separation of a tie. `d_rel` is the relative length of a tie. `d_sig` is the same separation in units of the largest slot sigma; covariances are ignored, and it is reported for esd rows only. The combined rules are on the `any` rows: a cell is within when some zero-type edge passes the angle and some tie-type edge passes the length.
