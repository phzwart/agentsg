IUCrJ submission source
========================
Files:
  main_v9.tex      - LaTeX source (latest versioned draft; article base;
                     drops into IUCr class - see header)

Older drafts (main_v5…main_v7, "main _v8.tex") are kept for history only.

Build (any TeX Live / MiKTeX / Overleaf):
  pdflatex main_v9.tex
  pdflatex main_v9.tex      # second pass for \ref cross-references

For final IUCr submission, change the header to:
  \documentclass{iucr}
  \journalcode{J}              % IUCrJ
and move author/affiliation into IUCr's \author/\aff macros.
